Code you can actually run

Every artefact on this page is regenerated by GitHub Actions on every push — nothing is pre-baked. Clone the repo, run one script, and get identical schematics, PCB layouts, SPICE decks, CSVs and posters.

KiCad — ECG analog front-end

python3 src/build_kicad_case.py

Writes a schema-valid KiCad 8 project (.kicad_pro, .kicad_sch, .kicad_pcb), the KiCad netlist, a BOM CSV and a fab summary JSON with the full stack-up.

LibrePCB — portable netlist

python3 src/build_librepcb_case.py

Emits a full LibrePCB .lpp tree — project/, circuit/, boards/default/, flattened library/ — that opens unchanged in LibrePCB 1.x.

Ngspice — AC / tran / MC / noise

python3 src/build_ngspice_case.py

Writes four .cir decks, a generic single-pole op-amp .lib, a run_all.sh driver, and the four characterisation CSVs and posters.

Qucs-s — 50 MHz band-pass

python3 src/build_qucs_case.py

Writes rf_bandpass.sch (Qucs XML) and rf_bandpass.ngspice, computes S11/S21 from the ABCD chain and renders the Smith chart + S21 mag/phase posters.

Shared — art helpers

src/art_helpers.py

Palette (#2E7A7B / #D9A441), figure style, schematic and PCB mock-up primitives reused by every case — one set of visual rules across all four tools.

Pipeline — one entrypoint

python3 src/run_all.py

Runs all four cases sequentially, ~4 seconds end-to-end. Dependencies are numpy, scipy and matplotlib — no EDA tool required to regenerate the portfolio.

Qucs XML schematic capture with Ngspice back-end, linear S-parameter sweeps, harmonic-balance for non-linear RF, co-simulation with passive EM models.

Python · NumPy · SciPy

ABCD-matrix S-parameter solver, Monte-Carlo sweep harness, scipy.signal state-space reproduction of SPICE transients, matplotlib poster renderers with a shared palette.
